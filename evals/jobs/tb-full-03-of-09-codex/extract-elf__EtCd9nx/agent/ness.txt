Implemented `extract.js`.

- Parses little-endian ELF32/ELF64 binaries.
- Extracts 32-bit little-endian values from all `PT_LOAD` segments.
- Uses `0x400000` as the base for PIE binaries.
- Outputs decimal memory addresses as JSON keys and integer values.
- Handles final partial words with zero padding.

Verified with:

```bash
node extract.js /app/a.out > out.json
```

Validation confirmed 699 entries, valid JSON, integer values, and exact agreement with an independent ELF segment parser.
