Created executable `/app/filter.py`.

It:

- Accepts the HTML path as `argv[1]`
- Modifies the file in place
- Preserves untouched HTML formatting and content byte-for-byte
- Removes `<script>` blocks, event-handler attributes, dangerous JavaScript/VBScript URLs, unsafe CSS, risky `srcdoc`, refresh URLs, conditional-comment scripts, and SVG animation URL indirection
- Uses only Python’s standard library

Verified with:

- `py_compile`
- Safe-document byte-preservation tests
- In-place CLI tests
- Obfuscated XSS payloads, SVG payloads, CSS escapes, `srcdoc`, and refresh attacks
- Direct executable invocation via `/app/filter.py`
