Created `/app/filter.py`.

Features:
- Accepts the HTML path as `argv[1]`
- Modifies the file in place
- Removes `<script>` elements and JavaScript in SVG/HTML
- Removes `on*` event-handler attributes
- Removes obfuscated `javascript:`, `vbscript:`, and related URLs
- Handles dangerous `srcdoc`, `data:` URLs, meta refreshes, and legacy CSS JavaScript patterns
- Preserves safe HTML, attributes, whitespace, quoting, comments, tables, headers, and line endings without DOM reserialization
- Uses only Python standard-library modules

Verified with syntax checks, CLI behavior, CRLF preservation, safe-content byte preservation, and multiple XSS payloads.
