Implemented `extract.js`.

- Parses 32-bit and 64-bit ELF binaries.
- Extracts every 4-byte word from `PT_LOAD` segments.
- Includes zero-filled BSS memory.
- Uses ELF virtual addresses as JSON keys.
- Outputs unsigned integer values.

Verified with:

```bash
node extract.js /app/a.out > out.json
```

Validation passed:
- Valid JSON output
- 701 memory values extracted
- All values are integers
- Exact match against an independent ELF `PT_LOAD` parser
- `node --check extract.js` passed
