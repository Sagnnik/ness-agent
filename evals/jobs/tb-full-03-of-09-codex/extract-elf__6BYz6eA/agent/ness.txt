Created `/app/extract.js`.

It:

- Parses ELF32/ELF64 binaries.
- Reads all `PT_LOAD` memory segments.
- Uses `0x400000` load bias for PIE binaries.
- Extracts unsigned 32-bit little-endian memory words.
- Includes zero-filled BSS values.
- Outputs numeric JSON values keyed by decimal memory addresses.

Verified with:

```bash
node /app/extract.js /app/a.out > out.json
```

Results:

- 700 memory entries extracted.
- First address: `4194304` (`0x400000`)
- All values are integers.
- Independent segment validation confirmed every emitted value matches the binary’s loadable memory layout.
