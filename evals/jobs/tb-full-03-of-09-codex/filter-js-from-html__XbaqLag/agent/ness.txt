Created `/app/filter.py`.

Features:
- Accepts the HTML path via `argv[1]`
- Modifies the file in place
- Removes `<script>` blocks, including case variations and malformed blocks
- Removes event-handler attributes such as `onclick` and `onerror`
- Removes dangerous JavaScript-capable URL attributes, including encoded and obfuscated schemes
- Filters `srcdoc`, meta refresh URLs, unsafe CSS, SVG animation URLs, and plugin parameters
- Preserves safe HTML, formatting, whitespace, attributes, tables, headers, and byte encoding unchanged

Verified with:
- Python syntax compilation
- 19 focused sanitizer cases
- Malformed HTML and boundary cases
- Safe-content byte-for-byte preservation
- In-place CLI execution and file mode preservation
- Final security assertions for scripts, event handlers, and JavaScript URLs
