Implemented `/app/jump_analyzer.py`.

- Uses OpenCV background subtraction and connected-component tracking.
- Estimates the ground-contact level from the athlete’s approach.
- Detects takeoff and landing frames without hard-coding event frame numbers.
- Accepts an MP4 path as its sole argument.
- Writes `/app/output.toml` with the required fields.
- Uses zero-based OpenCV frame numbering.

Run with:

```bash
python3 /app/jump_analyzer.py /app/example_video.mp4
```

Verified output:

```toml
jump_takeoff_frame_number = 54
jump_land_frame_number = 62
```

`py_compile` validation also passed. The available runtime lacked the `toml` module, so the script emits the required two-line TOML directly without adding dependencies.
