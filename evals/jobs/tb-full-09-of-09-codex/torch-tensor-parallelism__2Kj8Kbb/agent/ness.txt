Implemented `/app/parallel_linear.py`:

- `ColumnParallelLinear`
  - Shards PyTorch linear weights across output features.
  - Shards and zero-initializes bias.
  - Gathers outputs along the last dimension.
  - Preserves gradients through the gather operation.

- `RowParallelLinear`
  - Shards weights across input features.
  - Expects pre-partitioned input.
  - Reduces partial outputs across ranks.
  - Keeps a full zero-initialized bias on each rank.

- Added shape and divisibility validation.
- Verified syntax with `py_compile`.

No runtime distributed tests were available in the repository, and PyTorch is not installed in the container.
