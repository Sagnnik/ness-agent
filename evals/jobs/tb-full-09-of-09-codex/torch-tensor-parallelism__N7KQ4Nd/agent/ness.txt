Implemented `/app/parallel_linear.py` with:

- `ColumnParallelLinear`
  - Shards PyTorch weights across output dimension.
  - Shards zero-initialized bias.
  - Gathers outputs along the last dimension.
  - Preserves local weight and bias gradients.

- `RowParallelLinear`
  - Shards weights across input dimension.
  - Accepts already-partitioned input.
  - Reduces partial outputs across ranks.
  - Keeps a full zero-initialized bias and adds it after reduction.
  - Preserves local weight and bias gradients.

The container has no Python/PyTorch runtime or tests available, so runtime verification could not be performed.
