Implemented `/app/headless_terminal.py` with `HeadlessTerminal(BaseTerminal)`.

Features:
- Persistent interactive `/bin/bash -i` process attached to a PTY
- Sources interactive startup files such as `~/.bashrc`
- Supports interactive programs and terminal line discipline
- Supports control/modifier bytes such as `"\x03"` for Ctrl-C
- Preserves shell state across calls
- Supports configurable environment, encoding, and shell
- Drains and exposes terminal output through `output` and `read_output()`
- Provides `close()` and context-manager cleanup
- Handles partial writes and continuous output safely

Installed system dependencies:
- `pexpect==4.9.0`
- `ptyprocess==0.7.0`

Verified with:
- Python compilation/import checks
- Startup-file sourcing
- Persistent shell commands
- Interactive Python input
- Ctrl-C interruption and shell recovery
- Continuous-output process handling
- Context-manager cleanup
