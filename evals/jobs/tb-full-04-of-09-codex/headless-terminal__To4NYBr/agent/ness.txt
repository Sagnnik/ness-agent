Implemented `/app/headless_terminal.py` with:

- `HeadlessTerminal(BaseTerminal)`
- Interactive `/bin/bash -i` launched through a real PTY
- Startup-file loading, including `~/.bashrc`
- Interactive child-program support
- Control characters such as `"\x03"` for Ctrl-C
- Configurable terminal dimensions and environment
- Output capture through `output` / `read_output()`
- Context-manager and cleanup support
- Bounded output draining for continuously-writing programs

Verification completed:

- `.bashrc` environment changes are loaded
- Commands work with split keystrokes and Enter
- `cat` and Python input work interactively
- Ctrl-C interrupts foreground processes
- Ctrl-D exits the shell
- Minimal environments receive a default `TERM`
- Import and abstract-interface checks pass
- Python compilation passes

No third-party dependencies were needed; the implementation uses Python’s standard-library PTY APIs.
