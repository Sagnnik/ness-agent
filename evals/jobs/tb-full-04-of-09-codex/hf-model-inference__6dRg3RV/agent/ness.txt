Implemented and started the sentiment service.

- Service: `/app/app.py`
- Model: `/app/model_cache/sentiment_model`
- Endpoint: `POST http://<host>:5000/sentiment`
- Binding: `0.0.0.0:5000`
- Background process: PID `573`
- Log file: `/app/sentiment_service.log`

Verified:

- Positive input returns HTTP 200 with positive/negative confidence scores.
- Negative input returns HTTP 200 with correct sentiment.
- Invalid `"text"` values return HTTP 400 with a JSON error.
- Model files were downloaded and saved locally.

Example request:

```bash
curl -X POST http://localhost:5000/sentiment \
  -H 'Content-Type: application/json' \
  -d '{"text":"I absolutely loved this movie."}'
```

Stop the service with:

```bash
kill 573
```
