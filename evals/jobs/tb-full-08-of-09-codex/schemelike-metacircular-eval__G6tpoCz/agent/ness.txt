Created `eval.scm`.

It implements:

- Association-list environments with lexical scoping
- `quote`, `if`, `define`, `set!`, `lambda`, `let`, `begin`, `progn`, and `cond`
- Closures and function application
- Primitive operations, list operations, mutation, I/O, and file reading
- Recursive self-interpretation through a preserved native application bridge
- One-line path reading while leaving remaining stdin available to the interpreted program

  ```

  15
  Done
  ```
- Provided test programs run successfully and match the direct interpreter’s output with equivalent input.
- Nested self-interpretation of `eval.scm` completes successfully.
