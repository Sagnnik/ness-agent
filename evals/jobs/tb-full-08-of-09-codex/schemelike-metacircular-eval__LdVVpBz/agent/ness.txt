Implemented `eval.scm` as a self-interpreting metacircular evaluator.

Key features:
- Reads exactly one program path from stdin, then leaves remaining stdin available to the interpreted program (`eval.scm:292-300`).
- Supports lexical environments, closures, `define`, `set!`, `lambda`, `let`, `if`, `cond`, `begin`, and `progn` (`eval.scm:175-276`).
- Dispatches all primitives provided by `interp.py`, including arithmetic, list operations, mutation, console I/O, and file I/O (`eval.scm:59-173`).
- Streams source expressions from files using `fread`, allowing programs with multiple expressions and enabling self-interpretation (`eval.scm:284-298`).
