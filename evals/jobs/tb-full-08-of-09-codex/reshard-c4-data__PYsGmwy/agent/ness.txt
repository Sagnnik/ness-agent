Implemented:

- `/app/compress.py`
  - Accepts `<input_dir> <output_dir>`.
  - Creates the output directory when needed.
  - Limits every directory to 30 entries.
  - Splits regular files into chunks of at most 15,000,000 bytes.
  - Stores original paths, modes, empty files/directories, and symlinks in metadata.
  - Requires an existing output directory to be empty to avoid accidental overwrite.

- `/app/decompress.py`
  - Accepts `<resharded_dir>`.
  - Validates metadata, chunk ranges, and chunk sizes.
  - Reconstructs the original structure in a temporary directory, then replaces the resharded contents in place.
  - Restores file content, paths, modes, empty entries, and symlinks.

- `/app/reshard_common.py`
  - Shared format, chunking, path, and bounded-fanout logic.

- `/app/pyproject.toml`
  - Dependency-free uv project configuration.
  - `uv sync` creates `/app/.venv`.
  - `uv.lock` was generated and verified with `uv sync --locked`.

Usage:

```bash
uv run /app/compress.py <input_dir> <output_dir>
uv run /app/decompress.py <resharded_dir>
```
