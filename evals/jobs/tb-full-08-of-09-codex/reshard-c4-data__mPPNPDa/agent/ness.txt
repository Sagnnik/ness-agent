Behavior:

- Creates the output directory when absent.
- Uses a 30-way directory fan-out.
- Splits files into 14,000,000-byte chunks, below the 15 MB limit.
- Stores manifests in bounded-size files.
- Preserves nested directories, empty files/directories, symlinks, permissions, file sizes, and SHA-256 checksums.
- Decompression validates the complete resharded dataset in a temporary directory before replacing the resharded directory in place.
- Compression requires the output directory to be new or empty.

  - 9,900 resharded files checked.
  - Zero size or directory-entry-limit violations.
  - Exact structure, content, and modes matched the original.

Usage:

```bash
uv run python /app/compress.py <input_dir> <output_dir>
uv run python /app/decompress.py <resharded_dir>
```
