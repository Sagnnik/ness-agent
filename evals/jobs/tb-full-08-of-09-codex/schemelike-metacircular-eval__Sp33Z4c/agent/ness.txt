Implemented `eval.scm`.

- Added association-list environments with lexical scoping and mutation support (`eval.scm:5`).
- Added tagged closures and support for `lambda`, `define`, `set!`, `let`, `if`, `cond`, `begin`, and `progn` (`eval.scm:214`).
- Added application of user procedures and all runtime primitives, including I/O and file operations (`eval.scm:140`).
- Reads one path from stdin, interprets the file via `fread`, and preserves remaining stdin for the interpreted program (`eval.scm:319`).

Verification:

- The direct, one-level, and two-level self-interpretation examples all produced:
  ```

  15
  Done
  ```
- `eval.scm` parses as 31 complete top-level forms.
