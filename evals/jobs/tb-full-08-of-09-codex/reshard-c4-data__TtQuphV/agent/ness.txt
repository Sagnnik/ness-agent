Implemented:

- `/app/compress.py`
  - Usage: `python /app/compress.py <input_dir> <output_dir>`
  - Creates the output directory if needed.
  - Uses a manifest plus payload chunks.
  - Enforces:
    - Maximum 30 entries per directory.
    - Maximum 15,000,000 bytes per file.
  - Supports nested directories, empty directories, Unicode filenames, empty files, and files larger than 15 MB.
  - Refuses to overwrite a non-empty output directory.

- `/app/decompress.py`
  - Usage: `python /app/decompress.py <resharded_dir>`
  - Reconstructs the original structure and contents in place.
  - Builds the restored tree temporarily before replacing the resharded contents.

- `/app/reshard_common.py`
  - Shared implementation for chunking, manifest generation, validation, and restoration.

- `/app/pyproject.toml`
  - Standard-library-only project with no external dependencies.
  - `uv sync` creates `/app/.venv`.
  - `/app/uv.lock` was generated and validated.
