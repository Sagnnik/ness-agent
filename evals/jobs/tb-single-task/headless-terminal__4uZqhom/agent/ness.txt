The implementation is complete. Here's a summary of what was created:

**`/app/headless_terminal.py`** — `HeadlessTerminal(BaseTerminal)`

| Feature | How it works |
|---|---|
| **Interactive bash shell** | Uses `pty.fork()` to spawn `/bin/bash -i` with a real pseudo-terminal |
| **Startup files sourced** | `-i` flag makes bash source `~/.bashrc` etc. automatically |
| **Modifier keys** | Raw bytes written to PTY master — `"\x03"` = Ctrl+C, `"\x04"` = Ctrl+D, etc. |
| **Interactive programs** | Works transparently (python REPL, cat heredoc, etc.) |
| **`send_keystrokes(keystrokes, wait_sec=0.0)`** | Writes input, optionally sleeps to let the command run |
| **`read_output(timeout=1.0)`** | Non-blocking read with select-based timeout |
| **`is_alive()`** | Checks child process existence |
| **`close()`** | Sends EOF via PTY close, escalates to SIGKILL, reaps child |
| **Importable as** | `from headless_terminal import HeadlessTerminal` |

No external dependencies needed — uses only the Python stdlib (`pty`, `os`, `select`, `time`).
