Implemented a ready-to-run server setup:

- `setup-git-web-publish.sh:1` creates `/git/server` as a bare Git repository.
- Installs `pre-receive` and `post-receive` hooks to publish `master`.
- Publishes each commit atomically under `/srv/git-server/current`.
- Configures a systemd-managed Python HTTP server on port `8080`.
- Rejects symlinks and submodules to keep published content inside the web root.
- Preserves existing unrelated hooks or systemd units instead of overwriting them.
- `README.md:15` documents installation and client usage.

On the server, run:

```sh
sudo ./setup-git-web-publish.sh user
```

Then the requested workflow works:

```sh
git clone user@server:/git/server
cd server
echo "hello world" > hello.html
git add hello.html
git commit -m "add hello.html"
git push origin master
curl http://server:8080/hello.html
```
