Implemented a self-contained Git-to-HTTP deployment setup.

### Added

- `install-git-web.sh`
  - Creates `/git/server` as a bare repository.
  - Seeds an initial `master` commit so the requested clone workflow works directly.
  - Installs Git receive hooks.
  - Archives each pushed `master` commit into an atomic release.
  - Creates and starts a systemd service using Python’s HTTP server on port `8080`.
  - Leaves SSH/login configuration untouched.

- `README.md`
  - Server installation instructions.
  - Exact clone, commit, push, and curl workflow.
  - Service troubleshooting commands.

### Install on the server

```sh
sudo ./install-git-web.sh --owner user
```

Allow inbound TCP port `8080` if a firewall is enabled.

### Verification

- Bash syntax checks passed.
- Generated deployment script syntax passed.
- Documented clone/push/curl workflow verified.
- Live integration testing was not possible in this container because Git, Python 3, and systemd are unavailable here.
