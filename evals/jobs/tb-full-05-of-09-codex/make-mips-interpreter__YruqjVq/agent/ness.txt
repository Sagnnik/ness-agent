Implemented `vm.js` with:

- ELF32 little-endian MIPS32r2 loading
- Sparse virtual memory for the large ELF heap/BSS
- MIPS integer instruction execution, delayed branches, HI/LO arithmetic, unaligned accesses, and required SPECIAL3 instructions
- Required hard-float COP1 operations
- Host-backed system calls for file I/O, timing, directories, rename/unlink, and exit
- Doom WAD/config/save-file access through the host filesystem
- Frame preservation:
  - `/tmp/frame.bmp`
  - `frames/frame_000000.bmp`, etc.

Running:

```bash
node vm.js
```

boots Doom, loads `doom.wad`, initializes the renderer, and saves the first frame before exiting. Continuous execution is available with:

```bash
VM_MAX_FRAMES=0 node vm.js
```
