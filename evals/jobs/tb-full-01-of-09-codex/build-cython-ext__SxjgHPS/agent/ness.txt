Implemented and installed pyknotid 0.5.3 globally for Python 3.13 with NumPy 2.3.0.

### Changes

- Cloned source to `/app/pyknotid`.
- Installed global build/runtime dependencies:
  - Cython 3.3.0
  - setuptools/wheel
  - NumPy 2.3.0
  - networkx, planarity, peewee, VisPy, SymPy, and related dependencies
- Fixed removed NumPy aliases throughout the package:
  - `np.int`/`np.long` → `int`/`np.int64`
  - `np.float` → `float`
  - `np.bool` → `bool`

- Fixed Python 3.13’s removed `fractions.gcd` import in `pyknotid/make/torus.py:14`.
- Added compatibility for current `planarity` graph attribute names in `pyknotid/representations/representation.py:338`.
